🌐 DOM Manipulation & Events

Berinteraksi dengan elemen HTML, mengubah teks, warna, dan merespons klik dari pengguna.

💡 Tips: DOM (Document Object Model) membuat HTML menjadi dinamis dan interaktif saat diakses dengan JavaScript.

1. Mengubah Teks & Style Elemen

Contoh textContent & style
<!-- HTML --> <h2 id="judul">Teks Awal</h2> <button id="btn">Ubah Teks</button> <script> const judul = document.getElementById("judul"); const tombol = document.getElementById("btn"); tombol.addEventListener("click", () => { judul.textContent = "Teks Berhasil Diubah! 🎉"; judul.style.color = "#1B3FA0"; }); </script>

2. Counter Sederhana (Tambah & Kurang)

Contoh Aplikasi Counter Sederhana
<button id="btn-minus">-</button> <span id="angka">0</span> <button id="btn-plus">+</button> <script> let count = 0; const angka = document.getElementById("angka"); document.getElementById("btn-plus").addEventListener("click", () => { count++; angka.textContent = count; }); document.getElementById("btn-minus").addEventListener("click", () => { count--; angka.textContent = count; }); </script>
