Setup & Antarmuka

Mengenal Figma, membuat akun, dan memahami tampilan kerja untuk web designer

Bagian 1: Setup & Antarmuka

1. Apa Itu Figma?

Figma adalah design tool berbasis browser yang digunakan untuk mendesain antarmuka website — dari wireframe kasar hingga mockup akhir yang siap diserahkan ke developer.

ToolKelebihanStatus
FigmaGratis, kolaborasi real-time, CSS handoff✅ Standar industri
Adobe XDTerintegrasi Adobe❌ Ditutup 2023
SketchEkosistem lengkap⚠️ Mac only
CanvaMudah dipakai❌ Bukan untuk UI
💡 Fun Fact: Tokopedia, Gojek, Traveloka, dan hampir semua startup Indonesia menggunakan Figma sebagai design tool utama.
Bagian 1: Setup & Antarmuka

2. Setup: Akun & File Pertama

Figma gratis untuk pemula. Daftar menggunakan email atau akun Google, lalu langsung mulai desain di browser tanpa install apapun.

  1. 1Buka figma.com → klik Sign Up dengan Google
  2. 2Klik "New design file" di dashboard → rename file proyek
  3. 3Buat struktur halaman (Pages) yang rapi sejak awal
  4. 4Simpan dengan menekan Ctrl+S — Figma juga auto-save
📁
Struktur pages yang direkomendasikan untuk proyek website: 🎨 Design System → 📐 Wireframe → 🖥️ Desktop → 📱 Mobile
Bagian 1: Setup & Antarmuka

3. Mengenal 5 Area Antarmuka Figma

Setiap area punya fungsi berbeda. Web designer paling sering bekerja di Canvas, Properties Panel, dan Layers Panel.

① Toolbar — Pilih tool aktif ② Layers — Struktur & halaman ③ Canvas — Area kerja desain ④ Properties — Ukuran, warna, layout
Bagian 1: Setup & Antarmuka

4. Frame Web: Ukuran Kanvas yang Benar

Di Figma, setiap "halaman website" dibuat dalam sebuah Frame. Pilih ukuran yang sesuai dengan device target — Figma sudah menyediakan preset ukuran populer.

⌨️
Tekan F untuk Frame tool → pilih preset di Properties Panel atau ketik ukuran manual
DeviceLebarKeterangan
🖥️ Desktop1440pxStandar desain web modern
💻 Laptop1280pxAlternatif desktop
📱 Mobile390pxiPhone 14 (paling umum)
📱 Android360pxGalaxy S series
💡 Pro Tip: Konten dibatasi max-width: 1200px di tengah frame 1440px — sama seperti CSS container di website nyata.

Tools Dasar Web

Shape, text, color, image — semua yang dibutuhkan untuk membangun elemen website

Bagian 2: Tools Dasar Web

5. Shape Tools — Membangun Elemen Web

Di web, hampir semua elemen adalah kotak (rectangle) — navbar, card, button, section. Ini adalah shape yang paling sering kamu gunakan.

⌨️
Tekan R untuk Rectangle  |  O untuk Ellipse  |  L untuk Line
  • Rectangle (R): Navbar, card, button, section background
  • Corner Radius: Setara border-radius di CSS — masukkan nilai di Properties Panel
  • Ellipse (O): Avatar, icon background, badge
  • Proportional resize: Tahan Shift saat resize untuk jaga proporsi
🎯 Latihan: Buat card produk: rectangle 320×400, corner radius 16px, lalu tambahkan rectangle dalam untuk area gambar, judul, dan tombol.
Bagian 2: Tools Dasar Web

6. Text Tool — Tipografi Web

Web typography mengikuti hierarki yang konsisten. Figma mendukung semua Google Fonts secara langsung — ketik nama font di Properties Panel.

⌨️

Bagian 2: Tools Dasar Web

7. Color & Fill untuk Web

Figma mendukung warna solid, gradient, dan gambar sebagai fill. Palet warna yang konsisten adalah kunci desain website yang profesional.

  • Solid Fill: Klik kotak warna di Properties Panel → masukkan kode HEX
  • Linear Gradient: Ubah mode dari Solid ke Linear — cocok untuk hero section
  • Image Fill: Ubah ke Image → Choose image — setara background-image CSS
  • Opacity: Atur di slider atau ketik nilai 0–100 di kolom opacity
🎨
Palet web yang direkomendasikan: Primary, Secondary, Neutral (Dark–Light), Semantic (Success/Warning/Error)
Bagian 2: Tools Dasar Web

8. Gambar & Placeholder di Desain Web

Figma memungkinkan gambar dimasukkan sebagai Fill pada sebuah shape — identik dengan background-image: url() di CSS.

  1. 1Buat rectangle sesuai ukuran area gambar
  2. 2Klik Fill → ikon gambar → Choose image
  3. 3Atur Image Fit: pilih "Fill" agar seperti object-fit: cover
🔌
Plugin Unsplash (gratis): Pilih rectangle → Plugins → Unsplash → cari foto → masuk otomatis. Tidak perlu download gambar manual!
💡 Tips: Untuk avatar/foto profil, buat circle (Ellipse) lalu masukkan gambar sebagai fill — hasilnya foto bulat dengan presisi sempurna.

Layout Halaman Web

Grid, Auto Layout, dan Constraints — pondasi desain web yang responsif

Bagian 3: Layout Halaman Web

9. Column Grid — Standar Layout Web

Website modern menggunakan sistem 12 kolom. Di Figma, column grid identik dengan CSS Grid atau Bootstrap 12-column grid.

  1. 1Klik frame desktop → Properties Panel → "+" di Layout Grid
  2. 2Ubah dari "Grid" ke "Columns"
  3. 3Count: 12, Margin: 120px, Gutter: 24px
  4. 4Mobile: Count: 4, Margin: 16px
📏
Desain semua elemen mengikuti garis kolom — ini setara dengan max-width: 1200px; margin: 0 auto; di CSS
Bagian 3: Layout Halaman Web

10. Auto Layout = Flexbox di Figma

Auto Layout adalah fitur terpenting untuk web designer. Cara kerjanya identik dengan display: flex di CSS — elemen otomatis menyesuaikan ukuran isinya.

⌨️
Select elemen → tekan Shift+A untuk menambahkan Auto Layout

11. Constraints — Desain Responsif

Constraints menentukan bagaimana elemen berperilaku saat ukuran frame berubah — mirip seperti unit %, position: fixed, atau min-width di CSS.

ConstraintsPerilakuContoh
Left + RightStretch penuhNavbar, footer
CenterTetap di tengahModal, popup
RightMenempel kananScroll-to-top button
BottomMenempel bawahFixed footer
ScaleProporsional resizeHero image
💡 Tips: Untuk preview responsif, coba resize frame kanan-kiri — elemen dengan constraint yang benar akan mengikuti perubahan ukuran.

Komponen Web

Component, Variants, dan Properties — bangun UI sekali, gunakan di mana saja

Bagian 4: Komponen Web

13. Komponen — Desain Sekali, Pakai Banyak

Komponen di Figma setara dengan React Component atau Vue Component — ubah di satu tempat, semua instance di seluruh desain otomatis ikut berubah.

⌨️
Select elemen → tekan Ctrl+Alt+K untuk jadikan komponen. Ikon berlian 🔷 muncul = berhasil!
  • Main Component: Template utama — edit di sini untuk ubah semua
  • Instance: Salinan yang dipakai di desain — tidak bisa edit struktur
  • Detach: Putuskan dari main component jika perlu edit mandiri
  • Reset: Instance bisa dikembalikan ke kondisi main component kapanpun
💡 Tips: Komponen yang baik: Button, Card, Navbar, Input, Badge, Modal, Toast, Footer. Buat ini dulu sebelum mulai desain halaman.
Bagian 4: Komponen Web

14. Variants — Satu Komponen, Banyak Tampilan

Variants memungkinkan satu komponen button punya banyak state berbeda. Untuk web, button punya minimal 3 state: Default, Hover, Disabled.

  1. 1Buat 3 versi button (Default, Hover, Disabled)
  2. 2Select semua → klik "Combine as Variants"
  3. 3Beri nama property: "State" dengan nilai Default | Hover | Disabled
  4. 4Setiap instance bisa di-switch state dari Properties Panel
💡 Variant lengkap button web:
State: Default | Hover | Active | Disabled
Size: Small | Medium | Large
Type: Primary | Secondary | Ghost | Danger
Bagian 4: Komponen Web

15. Component Properties — Komponen Fleksibel

Component Properties memungkinkan setiap instance dikustomisasi dari luar tanpa perlu masuk ke dalam komponen — persis seperti props di React.

🔘

Boolean

Show/hide elemen. Contoh: tampilkan badge "NEW", sembunyikan ikon panah

show-badge: true
📝

Text

Ubah teks langsung dari Properties Panel tanpa masuk ke dalam komponen

label: "Daftar"
🔄

Instance Swap

Ganti ikon atau gambar di dalam komponen tanpa keluar dari instance

icon: arrow-right
🎨

Variant

Switch antara tampilan berbeda (state, size, type) dari satu pilihan dropdown

size: "large"
⚛️
Analogi React: {'
Bagian 4: Komponen Web

16. UI Kit & Figma Community

Tidak perlu membuat semua komponen dari nol. Figma Community menyediakan ribuan UI kit gratis yang bisa langsung dipakai dalam proyek.

  2. 2Klik "Duplicate to your drafts"
  3. 3Di file desain → Assets Panel → ikon buku → pilih library
  4. 4Drag komponen dari Assets ke canvas

Styling & Design Token

Color Styles, Text Styles, dan Effect Styles — konsistensi desain di satu tempat

Bagian 5: Styling & Design Token

17. Color Styles = CSS Variables

Color Styles di Figma setara dengan :root { --color-primary: #7c3aed; } di CSS. Ubah satu style → semua elemen yang menggunakannya langsung update.

🎨
Klik kotak warna → ikon 4 titik → klik "+" untuk buat style baru. Gunakan penamaan kategori/nama (contoh: Primary/500)
/* CSS Equivalent */
:root {
  --primary-500: #7C3AED;
  --primary-600: #6D28D9; /* hover */
  --neutral-900: #0F172A; /* teks */
  --semantic-error: #EF4444;
}
Bagian 5: Styling & Design Token

18. Text Styles — Konsistensi Tipografi

Text Styles menjaga semua teks di desain menggunakan ukuran, berat, dan spasi yang konsisten — identik dengan class CSS seperti .text-h1, .text-body.

📝
Buat teks → atur ke target style → klik ikon 4 titik di Properties → "+" untuk simpan sebagai Text Style
/* CSS Equivalent */
.display-large { font-size: 72px; font-weight: 900; }
.heading-h1 { font-size: 48px; font-weight: 700; }
.heading-h2 { font-size: 36px; font-weight: 700; }
.body-md { font-size: 16px; line-height: 150%; }
.caption { font-size: 12px; color: #64748B; }
💡 Tips: Gunakan nama yang sama dengan kelas CSS yang akan dipakai developer — ini memudahkan proses handoff secara signifikan.
Bagian 5: Styling & Design Token

Export & Handoff

Prototype, Inspect Panel, dan Export — menyerahkan desain ke developer dengan presisi

Bagian 6: Export & Handoff

20. Prototype — Simulasi Website Interaktif

Prototype di Figma memungkinkan klien dan developer melihat bagaimana website benar-benar terasa saat digunakan — tanpa perlu coding.

  1. 1Klik tab "Prototype" di Properties Panel kanan
  2. 2Pilih elemen trigger (contoh: tombol "Pricing")
  3. 3Drag panah biru ke frame tujuan
  4. 4Atur interaction: On Click → Navigate to → Smart Animate, 300ms
  5. 5Klik ▶️ Present untuk preview di browser
💡 Tips: Gunakan "Fixed position" di frame untuk navbar yang sticky, dan "Overflow: Vertical scroll" untuk scroll behavior halaman.
Bagian 6: Export & Handoff

22. Export Aset untuk Website

Figma bisa export aset langsung ke format yang siap dipakai di website — PNG, JPG, SVG, WebP. Format yang tepat sangat berpengaruh ke performa website.

FormatGunakan UntukTips
SVGIkon, logo, ilustrasi✅ Selalu pilih SVG!
PNG 2xFoto, gambar detailUntuk retina display
WebPFoto modern, ukuran kecilDukungan browser luas
PDFPresentasi ke klienBukan untuk web
  1. 1Klik elemen → scroll ke bawah Properties Panel
  2. 2Klik "+" di Export → pilih format (SVG/PNG)
  3. 3Untuk PNG: tambah 2x untuk retina display
  4. 4Klik "Export [nama]"
