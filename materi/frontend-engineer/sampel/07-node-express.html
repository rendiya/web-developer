🟢 Pengenalan Node.js & Express

Contoh skrip dasar untuk menjalankan JavaScript di server menggunakan Node.js dan Express.js framework.

💡 Catatan: Kode pada halaman ini dijalankan melalui terminal komputer (CLI) menggunakan perintah node filename.js.

1. Menjalankan Skrip Node.js Pertama

File: index.js Jalankan: node index.js
// File: index.js const fs = require('fs'); console.log("Halo dari Node.js Runtime! 🚀"); console.log("Versi Node.js:", process.version); console.log("Sistem Operasi:", process.platform); // Menulis file di komputer fs.writeFileSync('pesan.txt', 'Halo, file ini dibuat oleh Node.js!'); console.log("File pesan.txt berhasil dibuat!");

2. REST API Sederhana dengan Express.js

File: app.js Install dulu: npm install express
// File: app.js const express = require('express'); const app = express(); const PORT = 3000; app.use(express.json()); let todos = [ { id: 1, tugas: "Belajar HTML & CSS", selesai: true }, { id: 2, tugas: "Belajar JavaScript", selesai: true }, { id: 3, tugas: "Belajar Express.js", selesai: false } ]; app.get('/api/todos', (req, res) => { res.json({ success: true, data: todos }); }); app.listen(PORT, () => { console.log(`Express API berjalan di http://localhost:${PORT}`); });
