🔧 Function & Arrow Function

Membuat kode yang reusable dengan function, parameter, return value, dan arrow function.

💡 Tips: Function adalah blok kode yang bisa dipanggil berulang kali. Seperti resep masakan — tulis sekali, masak berkali-kali!

1. Function Dasar

Contoh Membuat & memanggil function
function sapaUser(nama) { console.log(`Halo, ${nama}! Selamat belajar JavaScript di VINIX7! 🚀`); } sapaUser("Budi"); sapaUser("Andi"); sapaUser("Siti");
Output

2. Arrow Function (ES6)

Contoh Syntax singkat =>
const kali = (a, b) => a * b; const kuadrat = x => x * x; console.log("3 x 4 =", kali(3, 4)); console.log("5² =", kuadrat(5));
Output
