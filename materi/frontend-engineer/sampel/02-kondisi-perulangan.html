Kondisi & Perulangan

Mengontrol alur program dengan if/else, switch, dan berbagai jenis loop.

Tips: Klik Jalankan untuk melihat output langsung, atau Salin Kode lalu paste di Console browser (F12).

1. If / Else

Contoh Menentukan Grade Nilai
let nilai = 85; if (nilai >= 90) { console.log("Grade: A — Sangat Baik!"); } else if (nilai >= 80) { console.log("Grade: B — Baik!"); } else if (nilai >= 70) { console.log("Grade: C — Cukup"); } else if (nilai >= 60) { console.log("Grade: D — Kurang"); } else { console.log("Grade: E — Tidak Lulus"); }
Output

2. Ternary Operator

Contoh If/Else dalam 1 baris
let umur = 17; let status2 = umur >= 17 ? "Boleh buat SIM" : "Belum boleh buat SIM"; console.log("Ternary:", status2); let skor = 75; let hasil = skor >= 60 ? "LULUS" : "TIDAK LULUS"; console.log(`Skor ${skor}: ${hasil}`);
Output

3. Switch Statement

Contoh Menentukan Hari
let hari = new Date().getDay(); let namaHari; switch (hari) { case 0: namaHari = "Minggu"; break; case 1: namaHari = "Senin"; break; case 2: namaHari = "Selasa"; break; case 3: namaHari = "Rabu"; break; case 4: namaHari = "Kamis"; break; case 5: namaHari = "Jumat"; break; case 6: namaHari = "Sabtu"; break; default: namaHari = "Tidak dikenal"; } console.log(`Hari ini: ${namaHari}`);
Output
