Variabel & Tipe Data

Belajar cara menyimpan data di JavaScript menggunakan let, const, dan var.

Tips: Klik tombol Salin Kode untuk menyalin contoh, lalu buka Console browser (tekan F12) untuk melihat hasilnya. Atau klik Jalankan untuk melihat output langsung.

1. Mendeklarasikan Variabel

Contoh let vs const vs var
// Menggunakan let (bisa diubah nilainya) let nama = "Budi"; let umur = 21; nama = "Andi"; // Bisa diubah // Menggunakan const (tidak bisa diubah) const PI = 3.14; const negara = "Indonesia"; // Menggunakan var (cara lama, hindari!) var kota = "Jakarta"; console.log("Nama:", nama); console.log("Umur:", umur); console.log("PI:", PI); console.log("Negara:", negara); console.log("Kota:", kota);
Output

2. Tipe Data

Contoh 7 Tipe Data JavaScript
// String — Teks let teks = "Halo Dunia"; // Number — Angka (bulat & desimal) let angkaBulat = 42; let angkaDesimal = 3.14; // Boolean — true atau false let sudahLulus = true; // Null — Sengaja dikosongkan let dataBelumAda = null; // Undefined — Belum diberi nilai let belumDiisi; // Array — Kumpulan data let buah = ["Apel", "Jeruk", "Mangga"]; // Object — Data terstruktur let mahasiswa = { nama: "Budi", umur: 21, jurusan: "Informatika" }; console.log("Teks:", teks, "→ typeof:", typeof teks); console.log("Angka:", angkaBulat, "→ typeof:", typeof angkaBulat); console.log("Boolean:", sudahLulus, "→ typeof:", typeof sudahLulus); console.log("Null:", dataBelumAda, "→ typeof:", typeof dataBelumAda); console.log("Undefined:", belumDiisi, "→ typeof:", typeof belumDiisi); console.log("Array:", buah); console.log("Object:", mahasiswa);
